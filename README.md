## What I do

I turn ambiguous requirements into software that teams can confidently ship and maintain. Today I lead delivery for a six-person engineering team on a large DoD enterprise platform, setting technical direction while owning scope, sequencing, and stakeholder alignment.

My route into engineering leadership was not conventional. I supervised intelligence operations in the Marine Corps and mentored officers in law enforcement before leading software teams. The common thread is simple: understand the mission, make the hard calls visible, and help people do their best work.

## Current focus

- Leading full-stack delivery across React, Node.js, and PostgreSQL
- Building privacy-first software with strong security and accessibility foundations
- Exploring practical agentic engineering workflows that improve quality without hiding judgment
- Shipping independent products that combine engineering depth with intentional design

## How I work

```text
Understand the problem -> establish the constraints -> build the smallest durable solution -> verify it in the real world
```

I care about clear ownership, honest tradeoffs, accessible interfaces, secure defaults, and evidence before claims.

## Selected builds

### [ApplicantWizard](https://github.com/jcooler/Recruiting-Tool)

A full-stack applicant tracking system with a drag-and-drop hiring pipeline, document parsing, analytics, role-based access, and temporary demo workspaces. [Try the live application](https://applicantwizard.vercel.app/).

`Next.js` `TypeScript` `MongoDB` `Tailwind CSS` `Vitest`

### [Aurora](https://github.com/jcooler/aurora-newtab) · In development

A privacy-first Chrome new-tab dashboard with local-only data, customizable widgets, productivity tools, and no accounts or tracking.

`React` `TypeScript` `Chrome MV3` `Vite` `Vitest`

### [RuneRadar](https://github.com/jcooler/RuneRadar) · In development

A second-screen live map for Old School RuneScape. A RuneLite plugin streams player position to an interactive map with more than 4,000 points of interest, route planning, and privacy-controlled friend sharing. [Open the map](https://jcooler.github.io/RuneRadar/).

`Java` `JavaScript` `Leaflet` `WebSockets` `Node.js`

### [Blackglass Deep Jewel](https://github.com/jcooler/blackglass-deep-jewel)

A near-black VS Code theme with restrained jewel-tone syntax colors and complete workbench coverage. [View it on the VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=jcooler.blackglass-deep-jewel).

`VS Code Extension` `Theme Design` `TextMate` `Semantic Tokens`

### [QuantumVista](https://github.com/jcooler/crypto-app)

A live crypto-market dashboard with a sortable top-100 table, search, price charts, news, and a server-only market-data proxy. [Explore the dashboard](https://quantumvista.netlify.app/).

`React` `TypeScript` `TanStack Query` `Netlify Functions`

### [Meridian](https://github.com/jcooler/meridian)

A cinematic concept-car launch site built around a scroll-scrubbed 96-frame drive sequence, live telemetry, and intentionally choreographed motion. [Experience the site](https://jcooler.github.io/meridian/).

`React` `GSAP` `ScrollTrigger` `Canvas` `Vite`
